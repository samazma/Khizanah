# خزانة الإسلام الشاملة (الخزانة) — Al-Khizanah Al-Shamilah

**خزانة الإسلام الشاملة** (وتُعرف اختصاراً بـ **الخزانة**) هو مشروع مفتوح المصدر لإعادة بناء وتطوير برنامج المكتبة الشاملة المكتبي (الإصدار 3.64) بتقنيات حديثة، مع الحفاظ التام على التوافق الكامل مع قواعد البيانات الأصلية وإحياء المنظومات العلمية المتخصصة التي يعتمد عليها الباحثون وطلاب العلم.

---

### 🌟 أبرز مميزات المشروع

- **التوافق التام مع قواعد البيانات الأصلية:** قراءة وإدارة ملفات الكتب والأرشيفات والفهارس بصيغتها الأصلية دون فقدان أي بيانات أو روابط.
- **إحياء محرك تراجم رواة الأسانيد:** استعادة منظومة التراجم المتكاملة (تهذيب الكمال، تهذيب التهذيب، والمستدركون) مع البحث المركب، فك رموز الطبقات والمخرجين، والشبكة التفاعلية للشيوخ والتلاميذ والتكميل العكسي.
- **ربط المتون بالشروح والتفاسير:** عرض الآيات القرآنية تلقائياً في كتب التفسير، ودمج المتون مع شروحاتها ومزامنة المصورات (PDF).
- **معمارية حديثة وقابلة للتطوير:** مبني بلغة Python وواجهة Qt (PySide6) مع عزل طبقة الوصول للبيانات لضمان الاستقرار والسرعة وقابلية التوسع مستقبلاً.

## English Overview

**Al-Khizanah Al-Shamilah (Khizanah)** is a modern desktop re-engineering of the classic _Al-Maktaba Al-Shamela v3.64_ Islamic research library, built with **Python** and **PySide6 (Qt)**.

It preserves full compatibility with the legacy database schemas while restoring and modernizing critical scholarly tools—most notably the **Hadith Narrators & Isnad Graph Engine (تراجم رواة الأسانيد)**, Commentary/Text linking, and Tafsir cross-referencing.

- **Current Phase:** Internal milestone development toward `v1.0`. Public source code, architectural blueprints, and contribution guidelines will be published upon reaching `v1.0`.
